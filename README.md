# Student Score Prediction 🤖📊

A beginner-friendly Machine Learning project that predicts a student's score based on the number of study hours using Linear Regression.

## Features

* Uses study hours as input
* Trains a Linear Regression model
* Predicts the expected score
* Visualizes the relationship between study hours and scores

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## Machine Learning Algorithm

**Linear Regression**

The model learns the relationship between study hours and student scores and uses this relationship to predict a score for a given number of study hours.

## How to Run

Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn
```

Run the program:

```bash
python score_prediction.py
```

Enter the number of study hours when prompted.

## Example

```text
Enter study hours: 7

Study Hours: 7.0
Predicted Score: ...
```

The program also displays a graph showing the relationship between study hours and scores.
